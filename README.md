# 🚀 Algorithm-Study

동기들과 함께하는 알고리즘 문제 풀이 저장소입니다.

## 📅 스터디 규칙
- **주간 최소 분량:** 매주 최소 **3문제** 풀이
    - **권장 난이도:** **실버 2개 + 골드 1개**
- **문제 선정:**
    - **공통 문제:** 매주 2문제 지정 (모두 동일하게 풀이)
- **자율 문제:** 본인이 취약한 유형이나 풀고 싶은 문제 1문제 이상
- **마감 시간:** 매주 일요일 23:59까지 커밋 및 PR 완료
- **코드 리뷰:** 매주 월요일, 서로의 PR에 최소 1개 이상의 의견이나 질문 남기기

## 📂 폴더 구조
개인별 폴더를 생성하여 파일 충돌을 방지합니다.
`본인이름/문제번호_문제이름.확장자`

> 예시: `이종혁/1010_다리놓기.java`

## 💬 커밋 메시지 컨벤션
`작업분류: 문제번호_문제이름`
- `feat: 1010_다리놓기`
- `fix: 1010_다리놓기 `

>feat (기능): 새로운 문제 풀이 코드를 추가했을 때
>
> fix (수정): 기존에 올린 코드의 버그를 고치거나 로직을 수정했을 때
>
> docs (문서): README 파일 수정이나 주석 추가 등 문서를 편집했을 때
