## ⚠️ AI 사용 및 학습 가이드 (필독!)
우리의 목표는 스스로 생각하는 힘을 기르는 것입니다. 생성형 AI(ChatGPT, Gemini 등) 사용 시 아래 규칙을 꼭 지켜주세요.

1. **무분별한 사용 금지:** 단순히 "코드 짜줘"와 같은 식의 사용은 최대한 절제해 주시길 부탁드립니다.
2. **올바른 질문 방식:** - "이 문제에서 내가 생각한 ~한 접근 방식이 논리적으로 타당할까?"
    - "현재 내 코드의 시간 복잡도를 줄일 수 있는 아이디어가 있을까?"
    - 이와 같이 **본인의 고민과 방향성**을 먼저 제시한 뒤 질문하는 방식을 권장합니다.
3. **직접 타이핑:** AI가 제시한 아이디어를 참고하더라도, 코드는 반드시 본인이 직접 작성하며 로직을 이해해야 합니다.

## 🛠️ 스터디 Workflow (진행 절차)
공동 저장소의 메인 브랜치를 보호하기 위해 아래 순서대로 진행해 주세요.

1. **브랜치 생성:** 작업 시작 전, 본인의 이름으로 된 브랜치를 생성합니다. (예: `feat/이종혁`)
2. **코드 작성:** 생성한 브랜치에서 본인 이름 폴더(`week01/이름/`) 생성 후 폴더 내에 소스 코드를 작성합니다.
    - 파일명 형식: `문제번호_문제이름.java` (예: `14916_거스름돈.java`)
3. **PR 생성:** 문제 풀이 완료 후, 본인의 브랜치에서 `main` 브랜치로 **Pull Request(PR)**를 날려주세요!
4. **리뷰 및 머지:** 동료들의 리뷰를 확인한 뒤, 최종적으로 `main` 브랜치에 반영합니다.
